# letalvoj.github.io

Personal one-pager. Plain static HTML — no build step, no generator, no blog.

- `index.html` — the page. All CSS is inline; the synthwave palette and the
  slitted sun are lifted from [SKOKAN](https://github.com/letalvoj/skokan).
- `skokan.png` — the game's app icon, also used as the favicon.
- `block-page/` — unrelated little utility page, left where it was.
